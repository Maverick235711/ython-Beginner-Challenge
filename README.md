
# Student Management System

## Project Description
The Student Management System is a beginner-level Python project
that allows users to manage student records using a menu-driven
program.

Student details are stored in a text file so that records remain
saved even after the program is closed.

## Features

1. Add Student
2. View All Students
3. Search Student by Roll Number
4. Calculate Average Marks
5. Exit

## Technologies Used
- Python 3
- File Handling
- Functions
- Loops
- Conditional Statements
- Exception Handling

## Project Structure

Student-Management-System/
|
|-- main.py
|-- students.txt
|-- README.md

## How to Run

1. Install Python 3.
2. Open the project folder in Terminal.
3. Run the following command:

   python3 main.py

## Concepts Used

- Functions to divide the program into smaller tasks.
- If-elif-else statements for menu selection.
- While loop to display the menu repeatedly.
- File handling to store and retrieve student records.
- Try-except to handle invalid inputs.
- Lists and strings to process student records.

## Data Storage

Student records are stored in students.txt.

Each record contains:
Name, Roll Number, Marks
